---
name: research
description: 针对高可信的一手资料调查一个问题，并将发现记录为仓库中的 Markdown 文件。当用户希望研究某个主题、收集文档或 API 事实，或把资料阅读工作委托给后台 agent 时使用。
---

启动一个**后台 agent** 执行研究，这样你可以在它阅读资料时继续工作。

它的职责：

1. 根据**一手资料**调查问题——官方文档、源代码、规范、第一方 API——而不是这些资料的二手解读。每项主张都要追溯到拥有该信息的原始来源。
2. 将发现写入一个 Markdown 文件，并为每项主张标注来源。
3. 将文件保存到仓库已有的此类笔记位置；遵循现有约定，如果没有约定，就放到合理的位置并说明保存在哪里。
