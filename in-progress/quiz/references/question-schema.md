# 题库 JSON 规范

`scripts/build_quiz.py` 接收一个 UTF-8 JSON 文件。它把题库验证后嵌入独立 HTML；答案索引不会在提交前渲染出来。

## 最小示例

```json
{
  "version": 1,
  "title": "网页知识快速测试",
  "source": "https://example.com/lesson",
  "description": "先独立作答；不确定时选择每题的「我不知道」；提交后查看解释。",
  "questions": [
    {
      "id": "q1",
      "category": "核心概念",
      "objective": "判断概念的适用条件",
      "source_anchor": "第 2 节：标题或段落开头",
      "type": "single",
      "prompt": "在题目给定条件下，哪一项最符合原文？",
      "options": ["选项 A", "选项 B", "选项 C", "选项 D", "我不知道"],
      "answer": [1],
      "unknown_index": 4,
      "unknown_label": "我不知道",
      "explanation": "原文在该条件下明确说明了选项 B；其他项遗漏了限制条件。"
    },
    {
      "id": "q2",
      "category": "操作边界",
      "objective": "识别多个同时成立的条件",
      "source_anchor": "代码块后的注意事项",
      "type": "multiple",
      "prompt": "选择所有正确项；不确定时只选「我不知道」。",
      "options": ["选项 A", "选项 B", "选项 C", "选项 D", "我不知道"],
      "answer": [0, 2],
      "unknown_index": 4,
      "unknown_label": "我不知道",
      "explanation": "只有 A 和 C 同时满足题干条件；多选必须完整选中这两个索引。"
    }
  ]
}
```

## 字段

### 顶层

| 字段 | 类型 | 必需 | 约束 |
| --- | --- | --- | --- |
| `version` | 整数 | 否 | 当前填 `1`；省略时按 `1` 处理。 |
| `title` | 非空字符串 | 是 | 页面主标题。 |
| `source` | 字符串 | 否 | 原网页 URL、文件名或课程名；用于署名，不作为可执行内容。 |
| `description` | 字符串 | 否 | 作答说明；省略时使用内置说明。 |
| `questions` | 非空数组 | 是 | 每项符合下方题目规范。 |

可选的 `metadata` 对象会原样保留在页面数据中，适合放 `mode`（`quick`、`standard`、`comprehensive`）和 `coverage_note`；`mode` 会显示为页面标签。不要放凭证或个人敏感信息。

### 题目

| 字段 | 类型 | 必需 | 约束 |
| --- | --- | --- | --- |
| `id` | 非空字符串 | 是 | 题库内唯一；建议使用 `q1`、`q2` 等稳定 ID。 |
| `category` | 非空字符串 | 是 | 章节或知识域，用于结果聚类。 |
| `objective` | 字符串 | 否 | 该题要检验的能力；建议填写。 |
| `source_anchor` | 字符串 | 否 | 标题、段落、代码块等证据位置；建议填写。 |
| `type` | 字符串 | 是 | `single` 或 `multiple`。 |
| `prompt` | 非空字符串 | 是 | 题干；多选题应明确「选择所有正确项」。 |
| `options` | 非空字符串数组 | 是 | 至少 2 个（至少一个知识选项和一个不确定选项），选项文本不可为空；默认把「我不知道」放在最后。 |
| `answer` | 非空整数数组 | 是 | 从 0 开始的选项索引；必须在范围内且不能重复，且不能包含 `unknown_index`。`single` 恰好 1 个，`multiple` 至少 1 个。 |
| `unknown_index` | 非负整数 | 是（旧题库可由生成器补齐） | 指向本题唯一的「我不知道」/同语种等价选项；建议指向最后一个选项，且不得与 `answer` 重合。 |
| `unknown_label` | 非空字符串 | 否 | 不确定选项的可见文本，默认是「我不知道」；非中文测验可填写自然的同语种等价短语，并确保 `options[unknown_index]` 与之完全一致。 |
| `explanation` | 非空字符串 | 是 | 提交后的答案解释，说明依据和关键条件。 |
| `points` | 正数 | 否 | 该题分值，默认 `1`；网页按题目整体正确计分。 |

生成器会拒绝未知题型、重复 ID、越界索引、空字符串、重复答案索引、无效 `unknown_index`、标签与索引不一致、把不确定选项当成正确答案以及不符合题型的答案数量，并给出带题号的错误信息。为兼容旧题库：若缺少 `unknown_index`，生成器会优先识别唯一一个与 `unknown_label`（默认「我不知道」）完全相同的选项；若不存在，则在末尾补上该标签并记录其索引。新题库仍应显式写出 `unknown_index`，并在非中文测验中显式填写 `unknown_label`。

### 「我不知道」选项

每题必须恰好有一个主动弃答选项。中文题库使用「我不知道」，其他语言使用 `unknown_label` 指定含义明确且全库一致的等价短语，并让 `unknown_index` 指向它。它是学习者的信心信号，不是材料中的知识断言，因此永远不写入 `answer`，也不与任何知识选项合并。

## 判分规则

- `single`：用户选中的索引必须与 `answer` 中唯一索引相同；选中 `unknown_index` 计为已答但不得分，并标记为「自报不确定」。
- `multiple`：用户选中的知识选项集合必须与 `answer` 集合完全相同；界面应让 `unknown_index` 与其他选项互斥，不确定时只选它。选择 `unknown_index` 计为已答但不得分，并标记为「自报不确定」；多选没有部分分。
- 每题答对获得该题 `points`，答错或未答得 0 分。总分是所有题目分值之和，页面同时显示分数和百分比。
- 未答题允许提交，结果区会单独显示未答题数；未答题不当作答错的知识结论。「我不知道」不是未答题，应在报告中单独统计，作为需要补学的信号。

## 出题检查表

1. 题干给出足够上下文，答案可以从来源材料推出。
2. 只有一个最佳单选答案；多选的正确集合边界明确，并为每题添加唯一的「我不知道」选项且不将其放入 `answer`。
3. 干扰项对应真实误解、条件遗漏或概念混淆，不靠措辞陷阱。
4. 解释能回答「为什么这个对、其他项为什么不对」，并指向 `source_anchor`。
5. 题目之间不重复考同一句话；全覆盖模式下每个知识点至少有一个稳定题目 ID。
6. 示例命令、路径和代码以文本形式出现，环境假设写在题干或解释中。
7. 多选题的不确定选项与其他选项互斥；解释或题面清楚说明选择「我不知道」会计为已答但不得分。

## 结果复盘格式

网页的「复制错题报告」会生成纯文本，包含来源、总分、未答题数和「自报不确定」数，以及每道已答错题、自报不确定题和未作答题的：题目 ID、章节、学习目标、题干、用户答案、正确答案、解释和证据锚点。报告把三类情况分开：选择「我不知道」表示主动不确定，留空表示未作答，其他错误选择才用于判断具体误解。用户把这段文本发回后，可按章节和目标分析薄弱点；不要仅凭百分比推断具体原因。
