# Critical Thinking：批判性思维分析论证

基于布朗 & 基利《学会提问》的方法论。核心信念：**通往合理结论的道路往往从问题开始，并且一路都有问题相伴**。批判性思维不是抬杠的工具，而是一套相互联系、环环相扣的关键问题——在适当时间提出并回答这些问题的能力和意愿。

## 两条基本原则（先内化，再分析）

1. **强势批判性思维，而非弱势**。弱势批判性思维是用这套方法捍卫自己现有的立场；强势批判性思维是用它评估**所有**断言，尤其是自己的看法。分析用户自己的观点时，不要手下留情——这可能恰恰为用户坚定看法提供更坚实的基础。
2. **警惕一厢情愿**。「似是而非」——那些我们希望或喜欢它是真的想法——是批判思考的大敌。始终问一句：「是不是因为我希望它是真的，它才显得是真的？」

## 分析流程：十二个关键问题

拿到一段论证（文章、观点、决策、方案），按下面的顺序逐一提问。不需要每个问题都长篇展开——**只有在分析推理过程中真正关键的点才值得写**，无关紧要的瑕疵略过即可。

### 1. 论题和结论是什么？

先找到论题（引起讨论的问题）和结论（作者想让你接受的观点），这是一切后续分析的前提。

- 论题分两类：**描述性论题**（世界是什么样，如「什么是家庭暴力的主要诱因」）和**规定性论题**（世界应该是什么样，如「公立学校应该收费吗」）。分清这两类，因为后面价值观假设只对规定性论题起作用。
- 找结论的线索：指示词（因此、所以、由此可见）、特殊位置（开头或结尾）、排除不可能是结论的东西（数据、例子、定义）、看作者的感情倾向。

### 2. 理由是什么？

一个人有没有头脑，主要标志就是看他能否提供充足的证据支撑看法。没有理由支撑的结论只是观点，不是论证。把「结论 + 支撑它的理由」这个骨架先摆出来。

### 3. 哪些词语意思不明确？

- 只有**出现在推理过程中、意思不明确的关键词**才重要——抽象词汇（「自由」「见效」「好男人」「着装不当」）比具体词汇更危险，逐一考察所有词是浪费，盯住关键词。
- 小心**带感情色彩的词**：它们绕过描述性意义通道直接连接情感线路，让思维短路。政治语言是重灾区——「福利」指给我们不喜欢的人的帮助，「扶贫」指给我们热爱的人的资助；最危险的政变也可以叫「改革」。
- 检验方法：换一个同样成立但含义不同的定义代入，看结论是否仍然成立。

### 4. 价值观假设和描述性假设是什么？

论证表面可见的部分常常穿着华丽的外衣，真正支撑它的往往是没说出来的假设。

- **价值观假设**（只对规定性论题）：特定情形下偏爱一种价值超过另一种。例：「不该建核电厂，因为废料污染环境」背后的价值排序是环保 > 发电效率。找法：先假设理由成立，再问「要让这个理由支撑结论，作者必须在价值上偏好什么？」注意价值倾向随情境改变。
- **描述性假设**：对世界是什么样的未明说的想法。找法：思考理由和结论之间的鸿沟；寻找支持理由的想法；把自己放到对立立场（反串）；考虑其他能获得同样好处的途径。

### 5. 推理过程中有没有谬误？

谬误是推理中的欺骗手段。常见清单（详见 `references/fallacies.md`）：

人身攻击、滑坡、完美解决方案、偷换概念、诉诸公众/可疑权威、诉诸感情、稻草人、虚假两难、乱扣帽子、转移话题、循环论证。

### 6. 证据的效力如何？

对每类证据问不同的问题：

- **直觉**：私密性使其无法被检验，很多直觉反映强烈偏见——警惕单凭直觉的断言。
- **个人经历**：单一经历甚至经历总和都不足以构成有代表性的样本，「以我的经历来看」是以偏概全的高危信号。
- **典型案例**：生动具体所以极具说服力，也因此最受政客青睐。问：这个例子有代表性吗？有没有强力的反例？
- **当事人证词**：考虑选择性（没成为当事人的人怎么想）、个人利益、省略信息、可靠性。
- **专家意见**：可信度取决于知识深度、研究水平、是否存在利益关系。网上人人都是「权威人士」。
- **研究报告**：样本覆盖率和随机性够吗？问卷有措辞偏见和语境偏见吗？回答真实吗？哪怕是片面的调查也承载信息，但要知道偏见所在，以免被过度说服。
- **类比**：类比总能找到相似点，所以相似点多不等于有说服力。看两点：两事物相同与相异的方式；相似点和结论的关联。**某种意义上所有类比都是错误的**——它假设两方面相似就能推出别的方面也相似。

没有一样证据能一锤定音，人们只是在寻找更好的证据。

### 7. 有没有替代原因？

千万不要贸然接受遇到的第一个解释。警惕四种因果谬误：

- **过度简化因果关系**：用一个不足以解释整个事件的因素解释一切。
- **因果混淆**：把因和果搞反，或看不出两者相互影响。
- **忽略常见原因**：两件事的相关其实是第三种因素在起作用（冰淇淋销量与犯罪率都受夏天影响）。
- **事后归因**：仅仅因为 A 发生在 B 之后，就认为 B 导致 A（踩狗屎后中彩票）。政商界最爱用，尤其对己有利时。

努力比较多种解释的可信度，很多事情不是只有一种解释。

### 8. 数据有没有欺骗性？

- 问数据如何采集、用来证明什么结论。
- 只有绝对数值时问百分比，只有百分比时问绝对数值。
- 找出被隐藏的对比数据（「四成公民不知道南北战争日期」——那以前的比例是多少？）。
- 统计数据看起来像权威事实，但对未经训练的思维者来说恰恰最易被操控。

### 9. 有什么重要信息被忽略了？

哪些省略掉的信息会影响推理？特别问一句：**被提倡的行动，其长期负面效果是什么？**

### 10. 能得出哪些合理的结论？

- 警惕**二分式思维**：很少有问题的答案是非黑即白。把结论限制在两个以内，无穷可能性就急剧减少了。
- 更好的答案往往带限定条件：「如果……，那么结论成立」。练习在接受作者理由的前提下，得出多个带条件的备选结论——例如食堂案例：接受同样的三条理由，既能得出「食堂失责」，也能得出「若目标是低浪费/低价格则食堂不失责」。
- 结论要有把握但留有余地：**有理有据时做事信心百倍，下结论时不可犹疑，但一定要扪心自问：「我的观点有没有可能是错误的？」**

## 输出格式

分析结果用下面的结构呈现（可根据材料复杂度裁剪，简单的论证不必写全）：

```
## 论证骨架
- 论题：（描述性 / 规定性）
- 结论：
- 理由：1. ... 2. ...

## 关键问题发现
- 歧义词：（只列影响推理的，并说明不同理解如何改变结论）
- 隐藏假设：（价值观假设 / 描述性假设）
- 谬误：（名称 + 原文定位 + 为什么是谬误）
- 证据评估：（逐类评估效力）
- 替代原因：（至少给出 1-2 个竞争解释并比较可信度）
- 数据问题 / 省略信息：（如有）

## 结论
- 该论证的可接受程度：强 / 中 / 弱，为什么
- 更稳健的结论版本（带限定条件）
```

## 分寸与姿态

- **海绵与淘金互补**：先海绵式地充分吸收对方的论证（准确复述，不歪曲），再淘金式地提问筛选。没听懂就批判是稻草人谬误的自助版。
- **不要摆出「哈哈，我可逮住你的错误了」的态度**。最有用的办法是把关键问题提给当事人，邀请对话而非宣布胜利。分析的最终目标是更接近真相，不是赢得辩论。
- 批判性思维只是工具。证据永远不完美，分析者能做的只是在审慎思考后选择最可靠的观点——并且**宁可在理由充分、证据确凿时反复无常，也不要在缺乏论据、强词夺理的结论上执迷不悟**。
