# 长字幕总结模板与检查项

本文件只在字幕较长、需要分段综合，或用户要求更细的研究式总结时读取。

## 分段方法

1. 以 SRT cue 为最小单位，不在句子中间截断。
2. 每段目标约 8,000–12,000 个字符；遇到明显章节标题、说话人切换或主题转折时优先换段。
3. 为每段记录起止时间、核心论点、支持事实、例子和仍不确定的内容。
4. 综合时只保留跨段后仍有依据的结论；互相矛盾的说法并列呈现并标注时间。

## 分段记录

```markdown
### 片段 <编号> · [<开始>]–[<结束>]
- 主旨：
- 要点：
- 事实/数据：
- 例子或引用：
- 不确定性：
```

## 最终检查

- 每个关键事实都能在 `subtitle.srt` 中定位到时间戳。
- 摘要覆盖开头、主体和结尾，不只根据最先出现的观点下结论。
- 人工字幕和自动字幕的可靠性已写明；听不清的词不擅自补全。
- 事实、视频作者的观点、总结者的推断分开表达。
- 字幕未提及的视觉或背景信息不写成视频事实。
- 语言、专有名词、数字和单位没有在翻译或压缩时改变。
