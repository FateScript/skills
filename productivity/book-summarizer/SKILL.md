# PDF 书籍学习指南

阅读用户提供的 PDF 书籍，产出一份**可离线打开的单文件 HTML**。面向没有相关背景的读者：解释核心概念、章节关系和实际用途，同时保留原书的重要限定。若用户只要某几章或指定了读者水平，按其范围和水平调整。

## 1. 确定输入与输出

使用用户给出的 PDF 与输出路径；未指定输出路径时，在当前工作区的 `outputs/` 下以书名生成文件名安全的 `<书名>-study-guide.html`。若用户指定跳过或优先处理的章节，按其要求安排；否则依目录顺序覆盖所有正文篇章。仅在无法定位 PDF、章节范围有歧义或输出位置不可用时询问用户。

完成条件：PDF、章节范围和最终 HTML 路径已确定。

## 2. 盘点并阅读整本书

先取得页数、目录、章节页码、标题、作者与主题。环境提供 PDF 专用 skill 时，使用它的读取与验证流程；否则可用 `pdfinfo`、`pdftotext -layout` 和 `pdftoppm`。对扫描版 PDF 使用可用的 OCR 或逐页视觉读取；无法可靠识别的章节要如实标明，不能猜测内容。

逐章提取并阅读正文；篇幅很长时，把中间笔记保存在临时目录，避免一次将整本书放入上下文。每章记录：

- 本章要教会读者什么，以及 **3–7 个**关键观点；
- 新术语的简明定义、可帮助理解的生活类比，以及这些概念为何有用；
- 与前面章节的依赖关系，供 HTML 中的“建立在这些章节之上”链接使用；
- 三个能检验理解的复习问题及答案；
- 章节来源页码和内容难度。阅读时间优先按已提取文本估算；提取不可靠时不要给出精确数字。

数学、公式或代码密集的章节，要说明它们**解决什么问题、为何有效、何时适用**；若细节对理解结论不可缺少，则用简短示例解释，不用含糊类比代替关键条件。

完成条件：范围内每章都有可追溯的笔记；页码或扫描识别缺口已记录。

## 3. 生成学习指南

按 [HTML 结构与交互要求](references/html-guide.md) 生成单文件 HTML，CSS 与 JavaScript 内联，不依赖在线资源。每章依次包含：

1. 章节标题、一句话概览、难度标记与可可靠估算时的阅读时间；
2. **3–7 条核心收获**；
3. 主要概念的初学者解释和具体类比；
4. “为什么重要”的实际用途；
5. 指向所依赖前文概念的章节链接；
6. 本章新术语及一句话定义；
7. **恰好三个**可展开答案的复习问题。

用中文撰写指南，保留必要的原书术语；用户指定其他语言时遵从。正文引用章节和页码，便于回查。目录、侧栏搜索、明暗模式、移动端布局与打印样式按参考文件实现。

完成条件：所有目标章节都有上述七部分，导航和交互均可使用。

## 4. 核验与交付

检查章节数量与目录一致、章节链接有效、复习题答案隐藏且可展开、搜索和主题切换工作正常。将生成的 HTML 在浏览器中打开，检查桌面、窄屏与打印布局；发现截断、重叠或无法阅读的地方就修复。对于文本提取不完整的章节，在指南和交付说明中清楚标出。

最后提供 HTML 文件链接，并说明书名、作者、已处理章节数、跳过的章节及识别限制。
