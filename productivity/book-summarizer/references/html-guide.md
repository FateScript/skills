# HTML 结构与交互要求

生成 `book-summarizer` 的学习指南时读取此文件。交付物为单个可离线打开的 HTML；CSS、JavaScript 与数据都放在文件内，不引用 CDN、在线字体或远端脚本。

## 页面结构

- 顶部细进度条显示当前阅读进度。
- 桌面端固定侧栏按原书顺序列章节，显示章节号、标题、难度与可估算的阅读时间。当前章节随滚动高亮；侧栏搜索按标题即时筛选。
- 主区域先显示书名、作者、学习指南用途和阅读说明，再依次显示各章。
- 窄屏时侧栏收进可开合菜单；点章节链接后关闭菜单。
- 右上角提供明暗主题切换，选择保存在 `localStorage`；页面也尊重系统主题。右下角的“返回顶部”按钮只在滚动后出现。
- 每章给稳定的 HTML `id`，以便侧栏和“建立在这些章节之上”的链接跳转。

## 每章七部分

1. **章节头部：** 章节号、标题、一句话概览、难度（入门／进阶／高级）和可靠估算的阅读时间。难度依据该章先修知识与术语密度判断。
2. **核心收获：** 3–7 条完整句子，说明学完本章应记住的内容。
3. **核心概念：** 每个主要概念用容易理解的文字解释，配一个贴近现实的类比；涉及公式、代码或操作步骤时写明类比无法覆盖的关键条件。
4. **为什么重要：** 用两三句话解释概念的实际用途或与全书主题的关系。
5. **建立在这些章节之上：** 只链接确有依赖的前文章节；第一章或不存在依赖时可省略此行。
6. **小术语表：** 每个新术语用一句话定义；可加一键复制术语及定义的按钮。
7. **复习问题：** 恰好三个问题，答案放在 `<details>` 中，默认折叠。

章节头部或末尾标注原书对应页码，方便读者回查。

## 视觉与可访问性

整体呈现温暖、清晰的教科书风格。正文宽度适合连续阅读；概念类比使用醒目的左侧色条和淡色背景，“为什么重要”使用另一种清晰区分的强调色。浅色与深色主题都要有足够对比度。交互控件带可读标签，键盘可操作，焦点状态可见。

可以使用以下颜色作为起点，按实际对比度调整：浅色背景 `#FAFAF8`、正文 `#1A1A18`、强调色 `#C75B2A`；深色背景 `#18181A`、正文 `#F0EEE9`、强调色 `#E8936A`。使用本地系统字体，保持离线可用。

## 内联脚本

- `IntersectionObserver` 或等效方式更新侧栏当前章节。
- 进度条显示已滚动比例。
- 侧栏搜索即时过滤章节，并提示“没有匹配的章节”。
- 明暗主题切换记住选择；移动端菜单可开合，点击章节后关闭。
- 术语复制按钮在浏览器允许时复制文本，并给出短暂反馈；受限环境中仍能选择并手动复制文字。
- 返回顶部按钮在页面滚动后显示，点击平滑滚动到顶部。

## 打印与验收

`@media print` 隐藏侧栏、进度条、按钮和搜索框，使用浅色、高对比度排版，并让各章节从新页开始。检查窄屏不横向溢出、长标题不被遮住、章节链接与搜索结果正确、主题切换后文字仍可读。浏览器脚本失效时，全部章节内容仍应可阅读。
