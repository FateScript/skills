# GLOSSARY.md 格式

`GLOSSARY.md` 是这个教学工作区的标准语言。所有讲解、练习和学习记录都应该遵守其中的术语。创建术语表本身也是学习的一部分：能把一个概念压缩成紧凑定义，说明用户已经理解它。

## 结构

```md
# {主题}术语表

{用一两句话说明这个术语表覆盖的主题。}

## 术语

**肌肥大**:
在多次训练中，由机械张力和代谢压力驱动的肌肉增长。
_避免使用_: 增肌变大、练大

**渐进超负荷**:
随着时间系统性提高肌肉承受的要求，例如通过负重、训练量或强度。
_避免使用_: 更努力、升级

**RPE（主观用力程度）**:
对一组训练难度的 1-10 自评分，10 表示力竭，8 表示大约还剩两次重复余力。
_避免使用_: 努力分数、强度评分
```

## 规则

- **只在用户理解后才添加术语。** 术语表是压缩知识的记录，不是让用户通过阅读来学习的字典。如果用户刚接触某个概念，请等到他们能正确使用它之后，再把它提升到术语表中。
- **要有判断。** 当同一个概念有多个说法时，选择最好的那个，并把其他说法列为要避免的别名。语言就是这样被压缩的。
- **定义要紧凑。** 一两句话即可。定义这个术语是什么，而不是它做什么或怎么做。
- **在定义中使用术语表自己的术语。** 一旦某个术语进入术语表，就在所有地方优先使用它，包括其他定义内部。这样能让复杂术语之后更容易被理解。
- **在自然聚类出现时使用小标题分组**，例如 `## 解剖学`、`## 编程`。如果术语本身连贯，保持扁平列表也可以。
- **明确标记歧义。** 如果某个术语在更大领域中被宽泛使用，要写清楚本工作区的约定：“在这个工作区中，'组' 总是指正式工作组，热身组单独记录。”
- **随着理解加深而修订。** 用户第一周写下的定义，到第六周可能已经不准确。直接就地更新，不要保留过期条目。
