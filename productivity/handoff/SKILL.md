---
name: handoff
description: 将当前对话压缩成交接文档，方便另一个智能体接手继续工作。
argument-hint: "下一次会话会用来做什么？"
---

编写一份交接文档，总结当前对话，让新的智能体可以继续工作。将文档保存到用户操作系统的临时目录中，不要保存到当前工作区。

在文档中包含一个 "suggested skills" 部分，列出建议智能体调用的 skill。

不要重复已经记录在其他产物中的内容，例如 PRD、计划、ADR、issue、commit、diff。改用路径或 URL 引用它们。

删去所有敏感信息，例如 API key、密码或个人身份信息。

如果用户传入了参数，将其视为下一次会话的重点说明，并据此调整交接文档。
